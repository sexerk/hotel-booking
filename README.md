# СЕРВИС ПО БРОНИРОВАНИЮ ОТЕЛЯ
Backend-сервис для управления бронированием номеров в отеле. Проект реализован на Python с использованием Django REST Framework
и соответствует требованиям технического задания, включая архитектуру базы данных и контейнеризацию приложения.



## В рамках проекта реализован следующий функционал:

### Управление номерами
* добавление новых номеров;
* удаление номеров;
* получение списка номеров.

### Сортировка
* поддерживается сортировка списка номеров;
* сортировка возможна по цене и дате;
* направление сортировки: по возрастанию и по убыванию (asc / desc).

### Бронирование
* создание бронирований с указанием дат начала и окончания проживания;
* валидация корректности вводимых дат;
* обязательная привязка бронирования к конкретному номеру.

### Целостность данных
* реализовано каскадное удаление (`ON DELETE CASCADE`);
* при удалении номера автоматически удаляются все связанные с ним бронирования.

### База данных
* структура базы данных описана в SQL-схеме (`schema.sql`);
* стандартные миграции Django для развертывания проекта не требуются.

## Инструкция по запуску
### Вариант 1: Запуск с использованием Docker 
* Данный способ не требует установки Python и зависимостей на локальный компьютер.
* Убедитесь, что Docker Desktop запущен.
* В терминале, находясь в корневой директории проекта, выполните команду: 
```docker-compose up --build```
* После завершения сборки сервис будет доступен по адресу: http://127.0.0.1:8000/

### Вариант 2: Локальный запуск
#### Для запуска проекта без использования Docker выполните следующие шаги:

* Установите Poetry и зависимости проекта: 
```pip install poetry```
```poetry install```
* Активируйте виртуальное окружение:
* poetry shell
* Подготовьте базу данных.
* Запустите сервер разработки:
* python manage.py runserver
* Сервис будет доступен по адресу: http://127.0.0.1:8000/

## Endpoints
* POST	/rooms/add/	Добавление номера (параметры: description, price)
* GET	/rooms/	Получение списка номеров с возможностью сортировки (?sort_by=price&order=desc)
* DELETE	/rooms/<id>/	Удаление номера и всех связанных с ним бронирований
* POST	/bookings/create/	Создание бронирования (параметры: room_id, date_start, date_end)
* GET	/bookings/list/	Получение списка бронирований для конкретного номера (?room_id=1)
* DELETE	/bookings/<id>/	Удаление (отмена) бронирования
## Работа с базой данных
* В корне проекта находится файл schema.sql, содержащий SQL-код для создания таблиц.
